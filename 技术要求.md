## 1. 中间件连接信息
#### MySQL `test_ai`
- **JDBC URL** — `jdbc:mysql://localhost:3306/test_ai?characterEncoding=utf8&zeroDateTimeBehavior=convertToNull&useSSL=false&useJDBCCompliantTimezoneShift=true&useLegacyDatetimeCode=false`
- **用户名** — `root`
- **密码**  — `root`
#### Redis
- **Host**  — `localhost`
- **Port**  — `6379`
- **Password** — 通过环境变量 `REDIS_PASSWORD` 配置
#### Ollama
- **Base URL**  — `http://localhost:11434`
- **嵌入模型**    — `nomic-embed-text`
- **对话模型**    — `gemma3:4b` / `deepseek-coder`
#### DeepSeek
- **API Key** — 通过环境变量 `DEEPSEEK_API_KEY` 配置
- **项目中可用Model**  — `deepseek-v4-flash`
#### Nacos
- **Server Address**  — `localhost:8848`
#### Chroma

-  `CHROMA_HOST`:`CHROMA_PORT` → `localhost:8000`
#### Milvus
- `MILVUS_HOST`:`MILVUS_PORT` → `localhost:19530`，DB `default`
