# 示例公司售后与服务制度

## 退款政策

1. 用户在购买服务后的 7 个自然日内，且服务尚未被实际使用，可以申请全额退款。
2. 服务已经产生调用量、生成结果或人工交付后，按照未使用部分折算退款。
3. 退款申请需要提供订单号、购买账号和退款原因。
4. 审核通常在 2 个工作日内完成，审核通过后原路退回，到账时间一般为 3 至 7 个工作日。
5. 定制开发、一次性交付和明确标注不可退款的服务不适用无理由退款。

## 发票政策

1. 已完成支付的订单可以申请电子普通发票或增值税专用发票。
2. 发票申请需要提供订单号、开票抬头和纳税人识别号。
3. 电子发票通常在 1 个工作日内发送至用户邮箱。

## 人工服务

人工客服工作时间为周一至周五 09:00—18:00，法定节假日除外。紧急故障可以提交工单，系统将生成业务编号用于查询处理进度。
